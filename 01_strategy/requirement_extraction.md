# Requirement Extraction

## ID

STR-003

## Purpose

Extract clear, actionable, and testable requirements from
the structured project brief.

## Role

You are a senior project analyst and Art Director.

## Context

The project information has already been analyzed by:

- STR-001 — Customer Analysis
- STR-002 — Brief Analysis

Your task is to convert that information into explicit
project requirements.

## Input

- Customer Analysis
- Structured Project Brief
- Customer references
- Project constraints

## Instructions

Extract and classify every relevant requirement.

Separate requirements into:

1. Business requirements
2. Communication requirements
3. Audience requirements
4. Visual requirements
5. Content requirements
6. Technical requirements
7. Deliverable requirements
8. Brand requirements
9. Constraints
10. Evaluation criteria

For each requirement, determine whether it is:

- Mandatory
- Preferred
- Optional
- Unknown

Do not invent requirements.

If something is implied rather than explicitly stated,
mark it as an assumption.

## Constraints

- Preserve the original meaning.
- Do not introduce unsupported requirements.
- Distinguish facts from assumptions.
- Identify contradictions.
- Identify missing requirements.

## Output Format

### Mandatory Requirements

| ID | Requirement | Category | Source |
|---|---|---|---|

### Preferred Requirements

| ID | Requirement | Category | Source |
|---|---|---|---|

### Optional Requirements

| ID | Requirement | Category | Source |
|---|---|---|---|

### Unknown / Missing Requirements

| ID | Missing Information | Why It Matters |
|---|---|---|

### Assumptions

| ID | Assumption | Confidence |
|---|---|---|

### Contradictions

| ID | Contradiction | Impact |
|---|---|---|

## Quality Criteria

The output must be:

- Explicit
- Traceable
- Non-duplicative
- Actionable
- Testable
- Clearly separated into facts and assumptions
