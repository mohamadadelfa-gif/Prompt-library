## Prompt ID System

| Prefix | Category |
|---|---|
| STR | Strategy |
| RES | Research |
| VIS | Visual Analysis |
| VDNA | Visual DNA |
| ART | Art Direction |
| GEN | Generation |
| QC | Quality Control |

Example:

`STR-001`

STR = Strategy  
001 = Prompt number

---

## Version System

Prompts use version numbers.

`1.0` = First stable version

`1.1` = Minor improvement

`2.0` = Major restructuring
