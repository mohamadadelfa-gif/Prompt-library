# EBL Approved Visual Calibration Examples

Store only **human-approved** visual calibration assets here.

## Entry Requirements

Every added asset must have:

- `EXAMPLE_ID` from `EBL_visual_examples.md`;
- verified repository path;
- approval state;
- what the example teaches;
- related decision IDs;
- related asset ID where relevant;
- file hash when the image is used as canonical identity/calibration evidence.

## Rule

```text
FILE PRESENT
≠
APPROVED EXAMPLE
```

Do not place exploratory or review-candidate visuals here merely because they were generated successfully.
