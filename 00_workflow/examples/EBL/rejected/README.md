# EBL Rejected Visual Calibration Examples

Store only intentionally preserved **rejected/failure calibration** assets here.

## Entry Requirements

Every added asset must have:

- `EXAMPLE_ID` from `EBL_visual_examples.md`;
- related `FAILURE_ID` from `EBL_failure_memory.md`;
- a short statement of what is wrong;
- detection signal;
- correction/prevention rule;
- verified repository path.

## Rule

Rejected examples are training/calibration evidence, not usable design references.

```text
REJECTED EXAMPLE
→ LEARN THE FAILURE
→ DO NOT REPRODUCE THE VISUAL DEFECT
```
