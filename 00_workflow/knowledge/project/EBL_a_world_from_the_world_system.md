# 1. Series Purpose

**A World from the World** is a recurring English Beyond Language content series built around a meaningful line, passage, expression, cultural artifact, or small piece of language drawn from literature, film, essays, interviews, music, art, public discourse, or other cultural sources.

The series should not function as a generic quote page.

Its purpose is to use one carefully selected fragment as an entry point into a larger world of:

- language;
- culture;
- interpretation;
- thought;
- context;
- independent participation.

Core principle:

```text
SMALL FRAGMENT
→ LARGER CONTEXT
→ LANGUAGE / CULTURAL INSIGHT
→ INDEPENDENT INTERPRETATION
```

# 2. Input Contract

A production cycle may begin with one or more of:

- exact quotation or line;
- author / speaker / creator;
- source work;
- publication / film / recording date;
- film clip or still;
- soundtrack / music reference;
- contextual image;
- cultural theme;
- language-learning objective;
- human-selected reference asset.

When exact wording is supplied or approved by the human, it is **LOCKED** and must not be paraphrased unless explicitly requested.

# 3. Content Workflow

## Stage A — Source Selection

Select a fragment because it has enough semantic or cultural depth to open discussion.

Reject fragments chosen only because they are famous, motivational, visually attractive, or easily shareable.

The fragment should support at least one of:

- language learning;
- cultural understanding;
- interpretation;
- critical discussion;
- historical context;
- literary / cinematic / artistic awareness;
- independent expression.

## Stage B — Verification

Before publication, verify where possible:

- exact wording;
- author / speaker / creator;
- work title;
- date;
- film / episode / recording source;
- whether attribution is resolved or unresolved.

Never invent attribution.

If verification remains unresolved, mark it internally as unresolved rather than presenting uncertain metadata as fact.

## Stage C — Copyright / Rights Check

Use:

`00_workflow/knowledge/project/EBL_copyright_rules.md`

Operational shorthand:

```text
USE ONLY WHAT IS NEEDED
→ TRANSFORM IT
→ TEACH / COMMENT ON IT
→ DO NOT REPLACE THE ORIGINAL
```

For film-based content:

```text
SHORT RELEVANT CLIP
→ PAUSE / FREEZE
→ EBL TEXT
→ EBL RECORDED EXPLANATION
→ OPTIONAL SHORT RETURN TO CLIP
```

Do not treat 10, 20, or 30 seconds as an automatic safe-use rule.

For background music, prefer licensed, original, royalty-free, Meta Sound Collection, or eligible Instagram-library audio according to the intended use.

Credit is good attribution practice but **credit is not permission**.

## Stage D — Interpretation / Teaching Layer

The EBL contribution must add real value rather than merely decorating or reposting the source.

Possible value layers:

- explain a word or expression;
- interpret tone or subtext;
- explain cultural context;
- connect language to an idea;
- compare literal and implied meaning;
- ask a discussion question;
- add a short recorded explanation;
- connect the fragment to participation in real conversation.

## Stage E — Writing Lock

Before design begins, define:

- exact source fragment;
- attribution line;
- contextual copy;
- educational / interpretive point;
- optional discussion prompt;
- locked vs flexible wording;
- rights / source status.

Design may format approved writing but must not silently rewrite it.

# 4. Output System

The series may produce two coordinated outputs from the same approved content package:

## A. Instagram Story

Working format:

`1080 × 1920 px` — `9:16`

Primary use:

- fast encounter with the source fragment;
- cultural/language context;
- optional interaction;
- daily recurring series presence.

## B. Instagram Feed Post

Use the current approved EBL feed format for the specific campaign/template.

Primary use:

- more durable archive;
- stronger visual composition;
- potentially expanded interpretation or source context.

Story and feed outputs should share the same approved content package, but they are not merely resized copies of each other.

# 5. Visual Template Logic

## Series Header

Text:

**A WORLD FROM THE WORLD**

Role:

- series identifier;
- secondary to the selected line / fragment;
- use only once in the composition unless a specific approved format requires otherwise.

## Brand Logo

- Use the approved English Beyond Language logo or approved production signature.
- Keep branding secondary to content.
- Do not regenerate or redesign the logo.

## Primary Fragment

- Main visual hierarchy.
- Preserve exact approved wording.
- Use generous negative space.
- Typography may respond to literary, historical, cinematic, or cultural meaning while remaining readable.

## Attribution

- Place close enough to the fragment to make source ownership clear.
- Author / speaker / creator must be readable.
- Source title/date may be smaller but must remain legible when included.

## Contextual Image / Clip

- Supports meaning rather than acting as unrelated decoration.
- For film/video, use only the portion required by the approved teaching/commentary purpose.
- Preserve text readability and platform-safe areas.

## EBL Graphic Layer

Use restrained project-approved elements such as:

- circles;
- arches;
- irregular fields;
- thin lines;
- dots;
- grids;
- hand-drawn marks;
- painterly material texture.

Every decorative form should have a compositional or communicative role.

---

# 6. Visual Hierarchy

Default order:

1. selected line / fragment;
2. author / source;
3. contextual image / film / cultural evidence;
4. **A WORLD FROM THE WORLD** series identifier;
5. English Beyond Language logo;
6. supporting geometric / painterly layer.

Hierarchy may change when the content purpose requires it, but the source fragment must remain semantically central.

```text
SOURCE / HUMAN INPUT
→ SOURCE VERIFICATION
→ COPYRIGHT / RIGHTS CHECK
→ INTERPRETIVE PURPOSE
→ WRITING PACKAGE
→ HUMAN CONTENT LOCK
→ STORY DESIGN
→ FEED DESIGN WHEN REQUIRED
→ TYPOGRAPHY / LOGO / SOURCE QC
→ COPYRIGHT CONTEXT QC
→ HUMAN FINAL REVIEW
→ PLATFORM OUTPUT
```

Use the existing EBL memory, logo, typography, Story, and QC systems during production.

---

# 8. Remove / Avoid

- generic motivational-quote treatment;
- source fragments with no EBL interpretive purpose;
- paraphrasing exact approved quotations;
- invented author/source/date;
- repeated series title;
- decorative visuals that compete with the fragment;
- copyrighted clips/music used merely for atmosphere when rights are unresolved;
- assuming a short duration is automatically copyright-safe;
- treating credit as permission;
- stretching a feed design into Story format without Story-specific composition;
- regenerating the approved EBL logo.

---

# 9. QC Checklist

Before publication verify:

## Content

- exact wording preserved;
- spelling checked;
- attribution checked;
- source/date checked or unresolved state recorded;
- EBL interpretive/teaching purpose is clear;
- no unsupported contextual claim.

## Copyright Context

- clip/text/music use has an explicit production rationale;
- only the necessary amount is used;
- transformative EBL explanation/commentary is present when relying on that context;
- background music source/license route is known;
- credit is present where appropriate but not treated as permission.

## Visual

- **A WORLD FROM THE WORLD** appears correctly;
- fragment remains primary;
- attribution remains readable;
- logo fidelity preserved;
- EBL visual grammar preserved;
- contextual media supports meaning;
- no duplicate branding;
- Story safe area respected;
- feed and Story outputs remain coordinated but format-specific.

---

# 10. Core Series Rule

> **A World from the World takes one small piece of language or culture and opens it into a larger context for understanding, discussion, and independent participation.**
