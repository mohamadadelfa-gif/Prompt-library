# 3. Visual Language Memory

English Beyond Language uses a contemporary editorial/cultural visual language with restrained painterly character.

## Stable visual grammar

- warm ivory / paper ground;
- rust / burnt orange;
- ochre / mustard;
- deep navy / desaturated blue;
- muted deep green / olive;
- charcoal / black;
- editorial serif for conceptual or reflective hierarchy;
- clean sans serif for direct / operational / explanatory language;
- asymmetry;
- generous negative space;
- hand-drawn linework;
- circles, arches, grids, dots, signs, irregular fields;
- painterly texture used as visual character, not noise.

## Avoid by default

- generic language-school visual clichés;
- flags / classroom imagery;
- stock-corporate look;
- generic infographic systems;
- icon-grid dependence;
- neon / gratuitous gradients;
- random decorative shapes;
- literal Paul Klee copying.

## Klee-informed principle

Use transferable principles, not imitation:

```text
VISIBLE ↔ LEGIBLE
LINE AS MOVEMENT / PATH
SIGN BETWEEN IMAGE AND SYMBOL
READING-LIKE VISUAL SEQUENCE
DRAWING + PAINTING SYNTHESIS
INCOMPLETE FORMS / IMAGINATIVE CONTINUATION
```

Ask what a line, form, or color field **does** for meaning before adding it.

# 4. Typography Memory

## Semantic typography rule

Typography is selected and refined according to content function.

```text
MEANING
→ SLIDE / STORY FUNCTION
→ READING ORDER
→ FONT ROLE
→ WEIGHT
→ SIZE
→ ALIGNMENT
→ LINE BREAKS
→ SPACING
→ COLOR EMPHASIS
```

General EBL role tendency:

- **editorial serif** = conceptual, reflective, cultural, question/thesis language;
- **sans serif** = direct, practical, operational, explanatory language.

This is a semantic grammar, not a rigid every-slide formula.

## Typography integrity learning

Repeated raster darkening is not an acceptable fix for degraded type.

When text becomes faded, haloed, weak, outlined, ghosted, or partially erased:

```text
LOCK APPROVED COPY
→ USE CLEANEST APPROVED SOURCE
→ REMOVE ONLY DAMAGED TEXT AREA
→ RECONSTRUCT LOCAL BACKGROUND
→ REDRAW EXACT COPY ONCE AT NATIVE RESOLUTION
→ FULL-OPACITY TYPE
→ NO POST-RENDER RESIZE
→ 100% NATIVE QC
```

Remember:

```text
DARK RGB ≠ OPTICALLY SOLID TYPE
TEXT PRESENT ≠ TYPOGRAPHIC INTEGRITY
```

Check:

- solid glyph interiors;
- natural crisp antialiasing;
- uniform stroke density;
- no gray halo;
- no ghost edge;
- no accidental translucency;
- emphasis applied only to approved words.

## Carousel numbering learning

Numbering is a repeated system component.

Preserve:

- format;
- anchor logic;
- size relationship;
- weight relationship;
- slash spacing;
- hierarchy.

Local color may adapt only when required for contrast and must remain functionally consistent.

# 6. Final AI Production Memory

The finalization process is a controlled creative loop.

## Final-stage rule

```text
FINAL QUALITY = MAXIMUM COHERENCE
                WITH
                MINIMUM NECESSARY CHANGE
```

A correct final creative decision may be **PRESERVE**.

Classify each asset:

```text
P0 PRESERVE
P1 CLEANUP
P2 MICRO-REFINE
P3 SOURCE-BASED RECONSTRUCTION
P4 CONCEPTUAL CHANGE — HUMAN AUTHORIZATION REQUIRED
```

## Clean-source hierarchy

```text
1. LIVE / EDITABLE SOURCE
2. APPROVED CLEAN MASTER
3. APPROVED TEXTLESS / ELEMENT-FREE MASTER
4. CLEAN REGION FROM SAME ARTWORK
5. TARGETED LOCAL REPAIR
6. GENERATIVE RECONSTRUCTION — LAST RESORT
```

Do not keep patching a damaged derivative when a cleaner approved source exists.

## Closed-loop finalization

```text
SOURCE LOCK
→ WHOLE-WORK READ
→ MEANING / FUNCTION MAP
→ PRESERVE / INTERVENE
→ CREATIVE FINAL EDIT
→ DELTA REVIEW
→ HEAVY QC
→ LOCAL ROOT-CAUSE CORRECTION IF REQUIRED
→ RERUN FAILED GATE
→ GLOBAL COHERENCE CHECK
→ PASS_FOR_HUMAN_FINAL_REVIEW
→ HUMAN APPROVAL
→ FINAL MASTER
→ PLATFORM DERIVATIVE
→ LEARNING REVIEW
```

AI cannot self-authorize human creative approval.
