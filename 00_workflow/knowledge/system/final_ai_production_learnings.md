## SYS-FINAL-AI-001 — Preservation Is a Valid Final Edit

A late-stage AI process must not force change.

```text
IF CURRENT FORM ALREADY SUPPORTS
MEANING + IDENTITY + READABILITY + SEQUENCE
THEN PRESERVE
```

No-change decisions must be documented, not treated as skipped work.

---

## SYS-FINAL-AI-002 — Cleanest Approved Source First

When a derivative is damaged, do not keep repairing the damaged derivative if a cleaner approved source exists.

Priority:

```text
EDITABLE SOURCE
→ CLEAN APPROVED MASTER
→ TEXTLESS / ELEMENT-FREE MASTER
→ CLEAN SAME-ARTWORK REGION
→ TARGETED LOCAL REPAIR
→ GENERATIVE RECONSTRUCTION LAST
```

---

## SYS-FINAL-AI-003 — Mandatory Defects Before Optional Polish

Final-stage effort follows this precedence:

```text
CONTENT / FACTUAL FIDELITY
→ IDENTITY / MASTER FIDELITY
→ TYPOGRAPHY / LOGO READABILITY
→ ARTIFACT INTEGRITY
→ SYSTEM CONSISTENCY
→ PLATFORM READABILITY
→ OPTIONAL AESTHETIC POLISH
```

Do not beautify around unresolved mandatory failures.

---

## SYS-FINAL-AI-004 — Semantic Consistency Over Mechanical Uniformity

System elements must share role, hierarchy, and grammar.

They do not always need identical local color treatment when contrast conditions differ.

Allowed adaptation must be functional and explainable, not decorative variation.

---

## SYS-FINAL-AI-005 — Local Failure, Local Fix, Global Re-check

When one asset fails:

```text
DIAGNOSE ROOT CAUSE
→ FIX THE SMALLEST AUTHORIZED AREA
→ RERUN THE FAILED GATE
→ RERUN WHOLE-SET COHERENCE
```

Do not redesign unaffected assets merely because one slide failed.

---

## SYS-FINAL-AI-006 — Whole-Set Read Before Local Edit

For a carousel or multi-asset set, analyze the complete sequence before editing individual frames.

Each local decision must be tested against:

- sequence;
- pacing;
- family resemblance;
- variation;
- entry / development / shift / payoff;
- shared visual grammar.

---

## SYS-FINAL-AI-007 — Master First, Derivative Once

Preserve the archival / project master at its approved final resolution.

Create platform derivatives only after master approval.

Do not repeatedly resize the working master during revision.

---

## SYS-FINAL-AI-008 — QC Evidence Is Production Output

Final QC must generate evidence, not only a verbal PASS.

Minimum evidence for visual sets:

- full-set contact sheet;
- native-resolution critical-area inspection;
- realistic platform-size preview;
- relevant logo / typography close-ups;
- Heavy QC report;
- unresolved-risk record.

---

## SYS-FINAL-AI-009 — AI Production Pass Is Not Human Creative Approval

AI may return:

```text
PASS_FOR_HUMAN_FINAL_REVIEW
```

Only explicit human approval promotes the work to:

```text
FINAL_PUBLISHING_MASTER
```

## SYS-FINAL-AI-010 — Finalization Is a Closed Loop

The reusable loop is:

```text
SOURCE LOCK
→ WHOLE-WORK READ
→ FUNCTION MAP
→ PRESERVE / INTERVENE CLASSIFICATION
→ FINAL-AI-001
→ DELTA REVIEW
→ FINAL-AI-002 HEAVY QC
→ ROOT-CAUSE REVISION IF REQUIRED
→ HUMAN FINAL APPROVAL
→ MASTER + PLATFORM DERIVATIVES
→ LEARNING REVIEW
```
