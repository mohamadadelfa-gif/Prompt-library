# Reference Style Synthesis

## Purpose

Analyze supplied visual references at the level of **visual language, material behavior, formal grammar, emotional effect, and transferable design principles** before applying them to a production template.

The task is not to copy a painting, illustration, or existing layout. The task is to extract the characteristics that create its recognizable feeling and translate those characteristics into an original communication system.

## Why This Step Exists

A reference can influence a project in several different ways:

- visual surface
- mark-making
- shape language
- composition
- materiality
- rhythm
- emotional atmosphere
- cultural or intellectual tone

These must be analyzed separately. A production template should inherit only the approved, transferable principles.

## Analysis Layers

### 1. Formal Language

Identify:

- asymmetry
- irregular geometry
- natural or organic shapes
- line behavior
- proportion
- scale relationships
- negative space
- visual rhythm
- balance between order and freedom
- placement of graphic elements

### 2. Mark-Making / Brush Language

Analyze the physical character of the marks:

- brush looseness
- hand-drawn quality
- edge irregularity
- stroke variation
- opacity variation
- layering
- visible human gesture
- accidental-looking but controlled marks
- relationship between painted fields and drawn lines

Do not reproduce individual marks from the source. Extract the behavior.

### 3. Material / Surface Language

Identify:

- paper character
- paint texture
- pigment variation
- roughness
- translucency
- layering
- imperfect edges
- natural surface variation

Translate these into controlled texture rules appropriate to the medium.

### 4. Shape Language

Identify the recurring formal vocabulary:

- circles
- rectangles
- organic silhouettes
- symbols
- fragmented forms
- hand-drawn figures
- simple signs
- geometric fields

The goal is to build a **shape vocabulary**, not a collection of copied objects.

### 5. Composition Language

Analyze how the reference creates visual organization:

- asymmetry
- intentional imbalance
- breathing space
- visual anchors
- edge tension
- overlap
- open vs. closed composition
- relationship between text and image

### 6. Emotional / Psychological Effect

This is a required analysis layer.

Describe what the viewer should **feel**, not merely what the viewer sees.

For the supplied English Beyond Language references, candidate emotional qualities include:

- curious
- human
- thoughtful
- playful but intelligent
- culturally aware
- warm
- intimate
- exploratory
- imperfect in a deliberate and positive way
- calm without becoming sterile
- artistic without becoming decorative

These are hypotheses from the supplied references and must be validated against the customer's intended brand character.

### 7. Communication Effect

Determine what the style does to communication:

- does it make the message feel more human?
- does it slow down attention?
- does it invite curiosity?
- does it create cultural or intellectual depth?
- does it soften technical information?
- does it create distinction from generic educational graphics?

The emotional and communication effects must be preserved when the style is translated into an Instagram template.

## Translation Rule

Never translate the reference directly into a template.

Use:

```text
REFERENCE
   ↓
STYLE ANALYSIS
   ↓
EMOTIONAL EFFECT
   ↓
TRANSFERABLE PRINCIPLES
   ↓
BRAND CONSTRAINTS
   ↓
PLATFORM CONSTRAINTS
   ↓
ORIGINAL TEMPLATE SYSTEM
```

## Instagram Constraint

The reference style must be adapted for Instagram rather than reproduced as a painting layout.

The Instagram system must prioritize:

1. immediate readability
2. mobile-scale typography
3. strong hierarchy
4. repeatable content zones
5. consistent branding
6. carousel continuity
7. reusable templates
8. export-safe spacing

The target ratio for English Beyond Language remains approximately:

**70% communication clarity / 30% texture and artistic character.**

## Template Synthesis

After style analysis, combine the approved style principles with the existing Instagram template system.

The result should define:

- typography hierarchy
- content zones
- graphic zones
- shape vocabulary
- line vocabulary
- texture behavior
- color behavior
- spacing
- safe areas
- slide roles
- repeatable components

## Separation Rules

Do not confuse:

- Reference Style with Brand Identity
- Emotional Effect with Decoration
- Style Rule with Customer Requirement
- Template with Content Instance
- Reference Artwork with Approved Production Asset

## Decision Gate

PASS — style characteristics are sufficiently understood and can be translated into an original platform system.

CONDITIONAL — usable with explicit limitations or unresolved interpretation.

BLOCKED — references are insufficient, contradictory, or too ambiguous for responsible translation.
