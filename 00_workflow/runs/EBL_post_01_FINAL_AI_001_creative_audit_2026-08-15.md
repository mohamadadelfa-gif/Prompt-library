## Cross-Slide System Findings

### Typography
The carousel already contains a meaningful semantic typography system:

- conceptual / reflective statements → editorial serif;
- direct / operational problem statements and examples → sans-serif;
- accent rust → semantic emphasis, not decoration.

Do not force every slide into one font family. Consistency should come from role logic, hierarchy, spacing, and repeated visual behavior.

### Numbering
Numbering is a repeated system component. However, contrast may require color inversion against a dark field (for example Slide 2). Therefore the refined rule is:

```text
SAME FORMAT + SAME ANCHOR + SAME SIZE/WEIGHT RELATIONSHIP + SAME OPTICAL ROLE
COLOR MAY INVERT ONLY WHEN REQUIRED FOR LEGIBILITY AGAINST THE LOCAL BACKGROUND
```

Do not force black numbering onto a dark shape merely for literal color consistency.

### Logo
Use the same chosen logo master, anchor, optical size and secondary visual weight on all slides. No new support objects.

### Painterly Integration
The final set must read as one authored artwork family. Any repair patch, inpainting rectangle, halo, texture discontinuity, pasted-on text, or inconsistent local sharpness is a final-stage failure even when content is correct.
