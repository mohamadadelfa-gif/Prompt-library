# FINAL-AI-002 — Creative Synthesis, Heavy QC & Final Output

## Purpose

Use the full approved project context plus source-informed creative judgment to make the strongest coherent final version, then run a heavy multi-layer QC before producing the publishing master.

This is the final production phase.

## Governing Principle

```text
CREATIVE FREEDOM MAY INCREASE
CONTENT / FACTUAL FREEDOM DOES NOT
```

AI may improve how the approved idea is expressed. AI may not silently replace the approved idea.

Final quality is not measured by amount of change.

```text
FINAL QUALITY = MAXIMUM COHERENCE
                WITH
                MINIMUM NECESSARY CHANGE
```

# Part A — AI Creative Synthesis

## A0. Preservation Gate

Before proposing any new change, ask:

```text
DOES THE CURRENT FORM ALREADY SUPPORT
MEANING + IDENTITY + READABILITY + SEQUENCE?
```

If yes:

```text
PRESERVE
```

A preserve decision is valid completion of the synthesis step.

Do not introduce optional polish merely to demonstrate activity.

## A1. Whole-Work Read

Review the complete asset/set before touching any single detail.

Ask:

- What is the core argument / idea?
- What should the audience feel and understand?
- What is the first focal point?
- What is the final payoff?
- Does each element help the communication?
- Does the work feel authored as one coherent system?
- Does anything feel pasted on, mechanically repeated, weak, faded, over-decorated, or unresolved?

## A2. Meaning-to-Form Audit

For every major typographic or visual choice, test:

```text
CONTENT MEANING
→ SLIDE / FRAME FUNCTION
→ HIERARCHY
→ ALIGNMENT
→ SPACING
→ TYPOGRAPHY
→ LINE / SHAPE / COLOR BEHAVIOR
```

If a formal choice cannot be justified by meaning, approved identity, system consistency, or useful visual tension, challenge it.

If it is already justified and performing correctly, preserve it.

## A3. Focal-Point Audit

Each frame should have one primary visual entry point.

Reject:

- accidental equal competition;
- logo competing with content;
- decoration competing with message;
- too many high-contrast areas;
- unnecessary textual emphasis.

Secondary elements may counterweight or enrich the focal point but should not create confusion.

## A4. Typography Synthesis

Assess typography as semantic structure.

Check:

- font family appropriateness;
- weight hierarchy;
- line breaks;
- text block proportions;
- alignment;
- leading;
- tracking / kerning;
- optical density;
- color emphasis;
- relation to image / shapes;
- consistency across the set;
- role-specific variation.

Use `QC-TYPE-001` and `typography_native_reconstruction.md` whenever raster type integrity is in question.

If typography is damaged and a cleaner editable/textless source exists, use source-based reconstruction rather than repeated raster patching.

## A5. Spatial / Layout Synthesis

Evaluate:

- negative space;
- grouping;
- alignment;
- focal hierarchy;
- balance / asymmetry;
- local density;
- edge pressure;
- visual path;
- repeated system elements;
- deliberate variation.

Do not flatten the work into a generic grid if the approved identity depends on painterly/editorial asymmetry.

## A6. Painterly / Line / Form Synthesis

For Klee-informed work, do not ask only whether shapes look stylistically similar.

Ask:

- What does the line do?
- What does the color field do?
- Is line character appropriate to the subject/function?
- Is tension between line and color useful?
- Is a secondary reading available without harming the primary message?
- Are accidental-looking textures controlled and intentional rather than artifacts?

## A7. Sequential / Carousel Synthesis

Evaluate the set temporally.

Check:

```text
ENTRY
→ DEVELOPMENT
→ SHIFT
→ PAYOFF
```

For EBL Post 01:

```text
QUESTION
→ BLOCKAGE
→ OBSTACLES
→ SHIFT
→ AGENCY
→ EXPANSION
```

Assess:

- progression;
- pacing;
- contrast between neighboring slides;
- repeated motifs without monotony;
- visual release / compression according to meaning;
- whether Slide 1 creates continuation desire;
- whether Slide 6 provides a satisfying expansion/payoff.

## A8. Adaptive System Consistency

Consistency means stable role and grammar, not blind pixel identity.

For repeated elements such as numbering, logo signatures, labels, and metadata, preserve:

- format;
- semantic role;
- anchor logic;
- weight / size relationship;
- spacing logic;
- hierarchy;
- family resemblance.

Allow local adaptation only when function requires it and the approved project rule allows it, such as light/dark contrast inversion.

Reject arbitrary variation presented as optical compensation.

# Part B — Heavy QC

Heavy QC is a combined gate. Run all applicable modules rather than relying on one total score.

## Defect Precedence

Resolve failures in this order:

```text
1. CONTENT / FACTUAL FIDELITY
2. APPROVED MASTER / IDENTITY FIDELITY
3. TYPOGRAPHY / LOGO READABILITY
4. ARTIFACT / RASTER INTEGRITY
5. SYSTEM / CAROUSEL CONSISTENCY
6. PLATFORM READABILITY
7. OPTIONAL AESTHETIC POLISH
```

Mandatory failures cannot be offset by optional polish.

## B1. Content Fidelity — mandatory

Verify:

- exact approved copy;
- punctuation;
- approved emphasis;
- no added claims;
- no omitted points;
- correct CTA;
- correct sequence.

Any unauthorized content change => FAIL.

## B2. Typography Integrity — mandatory

Run `QC-TYPE-001`.

Inspect at:

- 100% native resolution;
- full-slide target size;
- reduced feed-size view.

Reject:

- faded text;
- gray halos;
- ghosting;
- inconsistent numbering grammar;
- altered hierarchy without justification;
- weak optical stroke density;
- repair rectangles / patch seams around reconstructed text.

## B3. Logo Integrity — mandatory

Run `QC-LOGO-001`.

Verify:

- correct master / approved variant;
- approved placement rule;
- optical clear-space;
- no collision;
- no replacement artifacts;
- no extra support objects;
- logo remains visually secondary when intended.

## B4. Visual Identity — mandatory

Check against approved project rules / Visual DNA:

- palette;
- typography character;
- painterly/material behavior;
- motif grammar;
- negative space;
- tone;
- exclusions.

## B5. Artistic / Painterly Quality

Check:

- visual weight;
- rhythm;
- tension;
- gesture;
- material variation;
- organic/geometric relationship;
- line function;
- color-field function;
- texture quality;
- intentional imperfection versus accidental artifact.

## B6. Carousel / System Consistency — mandatory for sets

Check:

- numbering grammar;
- logo system;
- shared typography grammar;
- stable margins/anchors where required;
- palette relationships;
- family resemblance;
- meaningful variation;
- sequential narrative.

Do not fail adaptive contrast treatment when the repeated element retains its approved role, format, anchor logic, scale relationship, and hierarchy.

## B7. Instagram Readability / Platform Check

Check:

- mobile/feed readability;
- first-glance hierarchy;
- supported crop/aspect ratio;
- edge safety;
- export sharpness;
- high-resolution source;
- platform derivative.

For square Instagram publication:

```text
ARCHIVAL / PROJECT MASTER = preserve approved working master
PLATFORM DERIVATIVE = 1080×1080 when a square delivery derivative is required
```

Do not repeatedly resize the working master.

Create the platform derivative only after master approval, then inspect the derivative itself at realistic viewing size.

## B8. Audience / Communication Check

Run audience-relevance logic from existing social/audience QC.

Ask:

- does Slide 1 stop the right audience?
- is the problem recognizable?
- does the sequence build trust / value?
- does the conclusion create a meaningful payoff?
- does the work remain intelligent rather than generic language-school content?

## B9. Artifact / Raster Inspection — mandatory

At native resolution inspect:

- text edges;
- logo cleanup areas;
- masking;
- clone seams;
- gray blobs;
- repair rectangles;
- unintended lines/dots;
- color discontinuity;
- compression;
- blur;
- AI artifacts;
- edge contamination;
- unwanted transparency.

If a damaged derivative fails and a cleaner approved source exists, route the correction back through the clean-source hierarchy rather than repeatedly patching the same raster.

## B10. Delta Integrity — mandatory for changed assets

For every changed asset verify:

```text
WHAT CHANGED?
WHY?
WHICH RULE AUTHORIZED IT?
WHAT WAS PRESERVED?
WHAT NEW RISK WAS INTRODUCED?
```

Unexplained change => REVISION_REQUIRED.

## B11. Evidence Package — mandatory

A verbal PASS is insufficient.

Produce:

- full-set master contact sheet;
- platform-size contact sheet;
- native-resolution critical-area QC;
- logo / typography close-ups where applicable;
- before/after evidence for meaningful changes;
- Heavy QC report;
- unresolved-risk record.

## B12. Human Final Approval — mandatory

AI may produce:

```text
PASS_FOR_HUMAN_FINAL_REVIEW
```

AI cannot grant the final creative approval itself.

# Heavy QC Decision Logic

```text
AI CREATIVE SYNTHESIS
        ↓
HEAVY QC
        ↓
ANY MANDATORY FAIL?
    ↙          ↘
  YES           NO
   ↓              ↓
ROOT-CAUSE      PASS_FOR_HUMAN_FINAL_REVIEW
DIAGNOSIS            ↓
   ↓              HUMAN APPROVAL
CLASSIFY FIX          ↓
P1 / P2 / P3 / P4  FINAL_PUBLISHING_MASTER
   ↓                  ↓
CLEANEST VALID     PLATFORM DERIVATIVES
SOURCE                ↓
   ↓              LEARNING REVIEW
SMALLEST SAFE
CORRECTION
   ↓
RERUN FAILED GATE
   ↓
RERUN GLOBAL COHERENCE
   └────────────→ HEAVY QC
```

Do not average a critical failure away with a high total score.

---

# Failure Re-Entry Rule

If Heavy QC finds a mandatory failure:

1. name the exact failed gate;
2. identify the root cause;
3. classify the fix as P1 / P2 / P3 / P4;
4. choose the cleanest valid source;
5. apply the smallest authorized correction;
6. rerun the failed gate;
7. rerun whole-set coherence;
8. rerun any downstream check affected by the correction.

Do not redesign unaffected assets.

```text
LOCAL FAILURE → LOCAL FIX + GLOBAL RE-CHECK
```

# EBL Post 01 Final Synthesis Questions

Before final output, explicitly answer:

### Slide 1 — Question
- is the question the strongest focal point?
- is only the approved phrase emphasized?
- does typography remain solid and unfaded?
- does the logo clear the reading zone?

### Slide 2 — Blockage
- does the composition communicate friction/blockage without becoming hard to read?
- does any contrast adaptation in numbering preserve the system role and hierarchy?

### Slide 3 — Obstacles
- are multiple obstacles readable without becoming infographic-like clutter?

### Slide 4 — Shift
- is the old → new question transformation unmistakable?

### Slide 5 — Agency
- does the definition feel stable/confident?
- are there exactly two supports?
- is numbering `05 / 06` system-consistent?
- is all typography optically solid?
- are there any repair rectangles or patch seams?

### Slide 6 — Expansion
- does the slide feel more open / concluding?
- is the thesis hierarchy clear?
- does the CTA function as the final action/payoff rather than another competing headline?
- are all prior cleanup regions artifact-free?
