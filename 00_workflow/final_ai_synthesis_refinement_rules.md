# Final AI Synthesis — Refinement Rules

## Purpose

Refine FINAL-AI-001 and FINAL-AI-002 using lessons learned during the English Beyond Language Post 01 final-production pass.

These rules are reusable workflow guidance. Project-specific copy and exact layout remain project-scoped.

---

## 1. Preserve-When-Performing Rule

Final creative synthesis is not required to change every slide.

```text
IF AN APPROVED ELEMENT ALREADY PERFORMS ITS SEMANTIC + VISUAL FUNCTION
→ PRESERVE IT
```

A deliberate no-change decision is a valid creative decision.

Reject gratuitous redesign performed only because a final AI stage exists.

---

## 2. Meaning → Function → Form

Every final-stage refinement must be traceable through:

```text
CONTENT MEANING
→ FRAME / SLIDE FUNCTION
→ VIEWER PRIORITY
→ TYPOGRAPHIC ROLE
→ ALIGNMENT / SPACING
→ COLOR / LINE / SHAPE BEHAVIOR
```

Do not change form without identifying the communication problem it solves.

---

## 3. Semantic Typography Roles

Typography may vary by role while remaining inside one visual system.

Typical role logic:

- conceptual / reflective / thesis language → editorial serif when supported by the project system;
- direct / operational / friction / action language → sans-serif when supported by the project system;
- accent color → semantic emphasis only, never automatic decoration;
- body/support text → subordinate to the focal statement while remaining optically solid.

Do not force one font treatment onto every type of message merely for superficial consistency.

---

## 4. Consistency ≠ Mechanical Sameness

System consistency means stable relationships, not necessarily identical local values.

For repeated system components such as carousel numbering, preserve:

- format;
- anchor logic;
- size relationship;
- weight relationship;
- baseline logic;
- optical role.

Color may invert only when the local background requires contrast and the component still reads as the same system.

```text
SYSTEM RELATIONSHIP = LOCKED
LOCAL CONTRAST SOLUTION = ADAPTIVE WHEN NECESSARY
```

---

## 5. Repair Source Hierarchy

When late-stage cleanup is required, choose the least destructive source in this order:

1. approved editable/live layer;
2. clean textless artwork master;
3. clean pre-damage approved raster master;
4. local texture reconstruction from the same slide;
5. inpainting only when no cleaner structural source exists.

Avoid repeated inpaint/recolor passes when a clean source layer exists.

---

## 6. Artifact Precedence Rule

An accidental artifact always loses to approved intentional structure.

Before polishing style, remove:

- repair rectangles;
- ghost marks;
- gray blobs;
- clone seams;
- residual old-logo marks;
- accidental lines/dots;
- faded raster halos;
- texture discontinuities.

Do not call an artifact an intentional painterly irregularity unless it is supported by the approved source/master.

---

## 7. Whole-Set First, Local Edit Second

For carousels:

```text
WHOLE SET READ
→ IDENTIFY SEMANTIC / SYSTEM WEAKNESS
→ EDIT ONLY THE FAILING LOCAL AREA
→ RECHECK WHOLE SET
```

Do not optimize one slide in isolation if the change damages pacing, family resemblance, hierarchy, or narrative progression.

---

## 8. Native Master First

All final typography and cleanup work should be completed on the archival/project master before platform resizing.

```text
NATIVE MASTER
→ NATIVE QC
→ FEED-SIZE QC
→ PLATFORM DERIVATIVE
```

Do not repeatedly resize the working master.

---

## 9. Heavy QC Must Include Creative and Technical Questions

Technical correctness alone is insufficient.

Heavy QC asks both:

```text
IS IT CORRECT?
AND
IS IT THE STRONGEST COHERENT EXPRESSION OF THE APPROVED IDEA?
```

Mandatory areas:

- content fidelity;
- typography integrity;
- logo integrity;
- visual identity;
- painterly/artistic quality;
- carousel narrative;
- system consistency;
- Instagram readability;
- audience relevance;
- artifact/raster integrity;
- native-size inspection;
- feed-size inspection.

---

## 10. Final-Stage Change Threshold

A final-stage change should be applied only when at least one of these is true:

- it fixes a mandatory QC failure;
- it materially improves semantic hierarchy;
- it materially improves reading flow;
- it restores approved visual/system consistency;
- it removes an artifact;
- it improves platform readability without harming the master;
- it resolves a human-identified weakness.

Otherwise preserve the approved candidate.

---

## Learned Example — EBL Post 01

- Slides 1–4 were preserved after the whole-carousel audit because their semantic/form relationship was already strong.
- Slide 5 required reconstruction from a clean textless master because visible repair rectangles remained behind the typography.
- Slide 6 required removal of faint cleanup artifacts below the CTA.
- Slide numbering remained a shared system, while Slide 2 used contrast inversion because the local background required it.

Promoted learning:

```text
FINAL AI QUALITY ≠ MAXIMUM NUMBER OF CHANGES
FINAL AI QUALITY = MINIMUM NECESSARY CHANGES + MAXIMUM COHERENCE
```
