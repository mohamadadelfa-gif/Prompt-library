# Visual DNA Extraction & Synthesis

## ID
VDNA-001

## Purpose
Synthesize the six VIS analyses into a coherent, transferable visual system. Extract principles rather than reproduce references.

## Role
Senior Art Director, Visual Identity Strategist, and Design Systems Specialist.

## Required Inputs
### Strategy
- STR-005 — Project Reconciliation

### Research
- RES-006 — Research Synthesis
- RES-005 — Visual Reference Research

### Visual Analysis
- VIS-001 — Composition Analysis
- VIS-002 — Color Analysis
- VIS-003 — Shape & Form Analysis
- VIS-004 — Texture & Material Analysis
- VIS-005 — Typography & Graphic Language
- VIS-006 — Lighting, Mood & Atmosphere Analysis

If required analysis is missing, mark the affected DNA area Unknown. Do not fill gaps from imagination.

## Core Rules
- Do not copy or imitate any individual reference.
- Do not simply summarize the VIS outputs.
- Prioritize recurring, evidence-supported principles.
- Preserve contradictions when they are intentional or unresolved.
- Every major DNA rule must be traceable to one or more VIS findings.

## Process
### 1. Recurring Principles
Classify findings as Strong, Moderate, or Isolated.

### 2. Relationships
Analyze interactions between composition, color, shape, texture, typography, lighting, and atmosphere.

### 3. Contradictions
For each conflict decide: Resolve, Preserve, Control, or Unknown. Explain why.

### 4. Hierarchy
Classify characteristics as:
- Core — must remain consistent
- Supporting — normally reinforces the system
- Flexible — may vary by application
- Avoid — contradicts the system

### 5. Visual Grammar
Define how components behave together using actionable rules, preferably **IF → THEN**.

### 6. Visual Character
Use precise, observable language. Do not rely on generic adjectives without supporting principles.

### 7. Boundaries
Define the Anti-DNA: what the system must not become and why.
