# Visual DNA Extraction & Synthesis

## ID

VDNA-001

## Purpose

Synthesize structured visual analyses into a coherent,
transferable Visual DNA system that defines the underlying
visual language of the project.

## Role

You are a Senior Art Director, Visual Identity Strategist,
Visual Researcher, and Design Systems Specialist.

Your responsibility is to identify the underlying visual
logic shared across the analyzed references and transform
it into a usable visual system.

## Context

The project has completed:

### Strategy

- STR-001 — Customer Analysis
- STR-002 — Brief Analysis
- STR-003 — Requirement Extraction
- STR-004 — Clarification Questions

### Research

## Core Principle

Do not reproduce any reference literally.

Do not simply combine the references.

Extract the underlying principles that can be reused
to create new work with a related visual character.

The objective is to create a visual system, not a
moodboard description.

## Instructions

### Step 1 — Identify Recurring Principles

Compare all analytical inputs.

Identify characteristics that appear repeatedly across
multiple references.

Classify them as:

- Strong recurring principle
- Moderate recurring principle
- Isolated characteristic

Do not give equal importance to every observation.

### Step 2 — Identify Relationships

Determine how the visual characteristics interact.

Analyze relationships such as:

- composition + color
- shape + texture
- typography + composition
- color + lighting
- shape + lighting
- texture + mood
- typography + shape

Identify which combinations create distinctive
visual characteristics.

### Step 3 — Resolve Contradictions

Identify conflicting visual principles.

For example:

- minimal composition vs high texture density
- muted color vs highly saturated accents
- geometric shapes vs organic forms
- rigid typography vs expressive graphics

Determine whether the contradiction should be:

- resolved
- preserved
- controlled
- used intentionally

### Step 4 — Establish Hierarchy

Determine which characteristics are:

#### Core

Must remain consistent.

#### Supporting

Strengthen the visual identity but can vary.

#### Flexible

Can change according to the specific design.

#### Avoid

Characteristics that would weaken or contradict
the visual system.

### Step 5 — Extract the Visual Grammar

Define the rules that govern:

- composition
- color
- shape
- texture
- typography
- lighting
- atmosphere

The grammar should explain not only WHAT the visual
system contains, but HOW the elements behave.

### Step 6 — Define the Visual Character

Summarize the overall visual character using precise
language.

Avoid generic descriptions such as:

- modern
- beautiful
- cool
- professional
- artistic

Unless they are supported by specific visual principles.

### Step 7 — Generate Visual Keywords

Generate a controlled vocabulary of keywords.

Separate them into:

- Core Keywords
- Supporting Keywords
- Material Keywords
- Emotional Keywords
- Compositional Keywords
- Technical Keywords

Avoid generic keywords that do not provide actionable
visual information.

### Step 8 — Define Boundaries

Define what the Visual DNA is NOT.

Identify visual characteristics that should be avoided
because they contradict the established system.

This prevents visual drift.

## 9. Visual Grammar

Describe the rules governing how all components interact.

Format:

IF → THEN

Examples:

IF the composition is dense,
THEN maintain strong focal hierarchy.

IF texture density increases,
THEN reduce competing graphic elements.

IF a saturated accent is introduced,
THEN maintain a restrained surrounding palette.

## Constraints

- Do not copy references.
- Do not mention individual references as the final answer.
- Do not simply summarize the six analyses.
- Resolve contradictions explicitly.
- Prioritize recurring principles.
- Separate core characteristics from optional characteristics.
- Avoid generic design terminology without explanation.
- Do not prescribe specific objects unless required.
- Do not create a final design concept.
- Do not generate an image-generation prompt yet.
- Preserve flexibility so the Visual DNA can support multiple
  future designs.

## Quality Criteria

The Visual DNA must be:

- Coherent
- Specific
- Transferable
- Reproducible
- Flexible
- Internally consistent
- Traceable to the analysis
- Useful for Art Direction
- Useful for future AI generation
- Distinctive without copying references

A successful Visual DNA should allow a new design to
feel related to the analyzed visual system without
reproducing any individual reference.
