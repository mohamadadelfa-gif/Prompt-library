# Visual DNA Extraction & Synthesis

## ID
VDNA-001

## Purpose
Synthesize the six VIS analyses into a coherent, transferable visual system. Extract principles rather than reproduce references.

## Role
Senior Art Director, Visual Identity Strategist, and Design Systems Specialist.

## Required Inputs
- STR-005 — Project Reconciliation
- RES-005 — Visual Reference Research
- RES-006 — Research Synthesis
- VIS-001 through VIS-006 — Visual Analysis

If required analysis is missing, mark the affected DNA area UNKNOWN. Do not fill gaps from imagination.

## Core Rules
- Do not copy or imitate any individual reference.
- Do not simply summarize the VIS outputs.
- Prioritize recurring, evidence-supported principles.
- Preserve contradictions when intentional or unresolved.
- Every major DNA rule must be traceable to one or more VIS findings.

## Process
1. Recurring Principles — Strong / Moderate / Isolated.
2. Relationships — how composition, color, shape, texture, typography, lighting, and atmosphere interact.
3. Contradictions — Resolve / Preserve / Control / Unknown.
4. Hierarchy — Core / Supporting / Flexible / Avoid.
5. Visual Grammar — actionable IF → THEN rules.
6. Visual Character — precise, observable language.
7. Anti-DNA — what the system must not become and why.

## Output Contract
- Core Visual Concept
- Visual Character
- Composition DNA
- Color DNA
- Shape & Form DNA
- Texture & Material DNA
- Typography & Graphic DNA
- Lighting & Atmosphere DNA
- Visual Grammar
- Core / Supporting / Flexible / Avoid table
- Visual Relationships
- Visual Keywords
- Anti-DNA
- One-Sentence Visual DNA
- Design Translation

Every major rule must include source VIS IDs.

## Provenance / Confidence
Material rules require source VIS IDs. Use Low / Medium / High confidence for derived interpretations.

## Gate Decision
Return exactly one canonical status:
- PASS — complete and traceable Visual DNA is ready for Art Direction.
- CONDITIONAL — usable with explicit non-blocking limitations.
- BLOCKED — required VIS evidence is missing, contradictory, or unsupported.

## Handoff
Pass the complete Visual DNA package to ART-001, including rules, provenance, unknowns, blockers, and flexibility boundaries.

## Quality Gate
The Visual DNA must be coherent, specific, transferable, flexible, internally consistent, traceable, and distinct without copying references.
