# EBL-AWORD — A Word Project

## Project Identity

- **Parent brand:** English Beyond Language
- **Project ID:** `EBL-AWORD`
- **Recall name:** `A Word`
- **Recall command:** `Recall "A Word" Project`
- **Public series title:** **A Word from the World**

> The recall name is internal. The public title shown on Posts and Stories is always **A Word from the World**.

## Purpose

A Word turns a meaningful cultural source into an editorial English-learning experience. The source is not decoration; it is the starting point for communication, reflection, and participation.

### Core content logic

**Source → Idea → English → Question**

### Core visual principle

**Structured underneath, alive on the surface.**

Approximate balance:

- **70% editorial clarity**
- **30% artistic texture**

## Canonical Assets and Systems

This folder stores the learned and reusable project system:

- [`VISUAL_SYSTEM.md`](./VISUAL_SYSTEM.md) — canonical visual grammar and fixed/variable rules
- [`STORY_TEMPLATE.md`](./STORY_TEMPLATE.md) — canonical Instagram Story template
- [`PROCESS.md`](./PROCESS.md) — the reference-analysis → template-extraction → QC process learned during development

## Permanent Rules

1. Use the official English Beyond Language logo as the fixed brand asset.
2. Public-facing series title is exactly **A Word from the World**.
3. Supplied quotation/source text must never be paraphrased.
4. Quote/text is visually primary; image/art supports meaning.
5. Geometry frames and organizes; it must not become decorative clutter.
6. Fixed system rules persist until explicitly updated.
7. Per-piece creative decisions do not become permanent rules automatically.

## Default Per-Piece Input

The minimum useful input is:

```text
Recall "A Word" Project
Source: ...
Exact text: ...
Mood/reference: ...   # optional
```

The system should then recall the fixed brand, Story structure, palette, typography, geometry, image treatment, and QC rules automatically.

## Change Control

- Permanent change: `Update "A Word" Project: ...`
- One-piece exception: `For this one only: ...`

Temporary instructions must not overwrite the canonical system.
