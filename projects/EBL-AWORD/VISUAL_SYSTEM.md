# A Word — Canonical Visual System

## 1. Identity

- **Brand:** English Beyond Language
- **Recall name:** A Word
- **Public title:** **A Word from the World**

The internal recall name must never replace the public title on published assets.

## 2. Core Principle

**Structured underneath, alive on the surface.**

Target balance:

- 70% editorial clarity
- 30% artistic texture

The system should feel literary, cultural, intelligent, contemporary, and restrained.

Avoid:

- generic motivational-poster aesthetics
- glossy advertising
- excessive saturation
- decorative clutter
- obvious AI-surrealism

## 3. Color System

### Base
- Deep charcoal / black

### Primary text
- Warm cream

### Secondary text
- Warm beige

### Accent
- Burnt orange / rust

### Supporting color
- Muted teal / desaturated green

### Optional support
- Warm brown / muted ochre

Orange is semantic emphasis, not general decoration.

## 4. Typography

### Inter
Use for:
- public series title
- functional information
- labels
- metadata
- system text

### Cormorant Garamond
Use for:
- quotations
- literary emphasis
- attribution
- cultural/source information

Quote typography should be large, literary, left aligned, tightly but readably led, and surrounded by generous negative space.

## 5. Logo System

Use the official English Beyond Language logo.

Rules:
- preserve proportions
- never distort
- never recolor
- do not separate internal forms
- integrate it into composition rather than treating it as a tiny watermark
- top-right is the default social placement
- Story usage is relatively large and visually architectural

## 6. Quote System

The quote/text is the primary visual element.

Use:
- warm cream as the base text color
- selective burnt-orange emphasis for semantically important words or phrases
- large quotation marks as optional graphic devices

Do not color entire paragraphs orange.

### Source fidelity

**Never paraphrase supplied quotation/source text.**

Attribution/source/date must be accurate and visually subordinate.

## 7. Geometric DNA

Geometry enters from edges and frames the content.

Use:
- thin rules
- small dots/circular markers
- circles and partial arcs
- quarter circles
- rectangles
- modular blocks
- asymmetric edge framing

### Typical distribution

**Top-left:** more active cluster with quarter circles, blocks, cream, teal, orange, and dark forms.

**Left side:** thin rule + small orange circular marker.

**Right side:** more restrained rule, arc, or small block.

**Bottom:** denser modular geometry that may overlap the image field.

Geometry must organize rhythm and hierarchy rather than compete with content.

## 8. Texture System

Apply subtle tactile texture across:
- background
- colored geometry
- photographic treatment

Preferred qualities:
- paper grain
- archival surface
- subtle noise
- restrained material texture

Avoid:
- heavy grunge
- fake scratches
- excessive vintage effects

## 9. Image System

Preferred image types:
- photography
- artwork
- archival imagery
- culturally meaningful source material

Preferred treatment:
- monochrome
- sepia
- muted duotone
- restrained cinematic contrast

### Meaning rule

The image must support or extend the source meaning. It should not be selected only because it is visually attractive.

### Transition rule

For Story layouts especially:

**Image → atmospheric gradient → dark quote field**

Avoid a hard rectangular boundary between image and text field.

## 10. Content Flow

### Story

**Series Header → Main Quote/Text → Attribution/Source → Image/Artwork**

### Feed Post

**Series Header → Main Quote/Text → Attribution/Source → Image/Artwork**

The quote leads the visual. The image supports it.

## 11. Fixed Elements

These stay consistent unless the project is explicitly updated:

- public title: **A Word from the World**
- official EBL logo
- hierarchy
- typography roles
- core palette
- quote-first structure
- geometric DNA
- image position logic
- image-to-dark fade logic
- editorial/cultural tone
- texture philosophy
- source-fidelity rule

## 12. Variable Elements

These may change for each piece:

- exact quotation/text
- highlighted words
- author
- source
- date
- image/artwork
- crop
- mood
- amount of sepia/monochrome treatment
- source-specific visual reference
- selective temporary texture variation

A one-piece variation does not become a fixed project rule automatically.

## 13. QC

Before approval:

- [ ] Correct EBL logo used
- [ ] Result feels editorial, cultural, and recognizably EBL
- [ ] Quote is visually dominant
- [ ] Exact text preserved
- [ ] Attribution accurate
- [ ] Orange emphasis selective
- [ ] Image supports meaning
- [ ] Image transition is natural
- [ ] Geometry frames rather than distracts
- [ ] Texture remains subtle
- [ ] Strong readability
- [ ] Public title reads exactly **A Word from the World**

## Master Rule

The visual system must remain recognizable even when the quote, source, image, and mood completely change.

**Structure stays constant. Meaning changes.**
